## Project Abstract

Assignment Planner will help college students organize coursework across multiple classes. Users will be able to create courses, record assignments with due dates and priorities, track completion, and view upcoming and overdue work in one place. The application will give students a clear overview of what needs to be done so they can plan their time and reduce missed deadlines.
